Projects

In my digital circuits course, I worked individually to design an interactive Frogger game implemented on a De1-SoC FPGA. The challenge was to build a reliable real-time digital system using finite state machines while handling user inputs and timing controls. I was responsible for designing and implementing the game's core logic, timing controllers, and input handling. The goal was to ensure smooth gameplay, accurate state transitions, and reliable button input. I designed the system's architecture using a multiple FSM approach to separate game logic and input debouncing. I implemented timing controllers to synchronize the game board and player movement and added debouncing logic to eliminate false button triggers. To validate the correctness of my SystemVerilog system, I wrote testbenches in ModelSim and iteratively simulated each module before integrating the full system in Quartus Prime. The final design passed 100% of simulation test cases and functioned reliably without missed inputs. The project strengthened my skills in FPGA design, verification, and debugging, as well as gave me hands-on experience building a real-time digital system.

My final project for EE271: Digital Circuits and Systems

As a part of my hardware fundamentals course, my team was tasked with designing a line-following robot capable of reliably tracking a line course in real time. The system had to integrate sensors, control logic, and mechanical design while meeting strict performance requirements. I was tasked with the design of the embedded system and its sensor interface, PCB design, and control logic. Our group's goal was to achieve stable closed-loop control while ensuring robust sensor readings. I helped design a custom PCB in KiCad to integrate line sensors with an Arduino microcontroller and implement closed-loop control logic to adjust motor outputs based on sensor feedback. I also contributed to mechanical design by modeling and fabricating a 3D-printed chassis in Fusion360. We iteratively tested and tuned our sensor thresholds and control parameters to improve tracking accuracy. Our robot achieved 100% course completion with consistent real-time tracking accuracy and ranked top 10 out of 40+ teams. This project reinforced my understanding of embedded firmware development, PCB design, and hardware-software integration.

My final project for EE201: Computer Hardware Skills

I had a personal project where I was building a third eye for the blind, a wearable navigation aid to help visually impaired users detect obstacles in real time. I designed a reliable, real-time embedded system that could sense obstacles in the environment and communicate information to the user in an intuitive way. I integrated ultrasonic sensors, thermistors, and vibrating motors with an Arduino using C++ code to handle real-time sensor data. I iteratively tested the device in different surroundings and refined placement and timing through experimentation. At the end of it, I successfully built a functional prototype that reliably detected obstacles and learned how sensor noise and different environmental factors affect real-world systems.
